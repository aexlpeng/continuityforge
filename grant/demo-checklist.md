# Demo Checklist

The demo should prove the pipeline, not hide it behind one polished montage.

## Minimum 90-second walkthrough

1. Show the original episode YAML and character bible.
2. Run `continuityforge plan` and display the 5s/10s decisions.
3. Inspect two adjacent shots' end/start state handoff.
4. Show the dry-run model route and request manifest.
5. Replace placeholder endpoint configuration with a verified fal endpoint.
6. Generate one short sequence and show request IDs/results.
7. Show one failure and how repair/regeneration is scoped to that shot.
8. Open the blank evaluation sheet and explain the benchmark.

## Evidence to display

- Public repository and passing CI
- At least three adjacent generated shots, not only isolated clips
- Current fal endpoint/API use
- One cost/latency summary
- Asset provenance statement
- Clear label for planned features

Avoid unlicensed music, celebrity likenesses, cloned voices, existing cartoon characters, confidential URLs, and API keys.
