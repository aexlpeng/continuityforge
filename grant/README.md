# Grant Materials

These drafts are deliberately evidence-first. Replace every bracketed field before submitting and attach a real rights-cleared demo when available.

## Recommended path

Apply to the **fal Research Grant** first. ContinuityForge is currently an open-source research scaffold, and fal's Research Grants page asks applicants to describe the project, goals, open-source alignment, and relevant work. It directs applications to `grants@fal.ai`.

The **Builder Grant** is a different path: fal currently describes it as credits for a direct generative-media app, for bootstrapped/indie teams in Europe and Asia, with applications through approved partners. Use that draft only after there is a first-class user-facing generation experience and a partner/referral route.

Official sources checked on 2026-08-31:

- https://fal.ai/grants
- https://fal.ai/builder-grant
- https://fal.ai/startups
- https://fal.ai/docs/api-reference/client-libraries/python

## Before sending

- [ ] Public repository URL works in a signed-out browser
- [ ] CI passes on the default branch
- [ ] README has one real screenshot, GIF, or demo link
- [ ] At least one live fal endpoint configuration is verified and dated
- [ ] Claims match actual results; planned work is labeled as planned
- [ ] Requested compute is tied to a pre-defined experiment matrix
- [ ] Applicant bio, location, links, and fal account email are filled in
- [ ] No API key, private media URL, or unlicensed asset is present
