# Keyframe Generation Contract

Generate a clean first-frame reference for a single planned shot.

Treat character-bible identity locks, location anchors, start state, aspect ratio, and camera framing as hard constraints. Compose for readable silhouettes and leave space for the declared action. Preserve handedness, wardrobe colors, prop positions, lighting direction, and screen state.

Avoid: identity drift, extra characters or limbs, wardrobe variation, illegible UI text, lens inconsistency, unmotivated depth of field, signature, watermark, or resemblance to an existing franchise.

Output one image. Do not depict the end state early.
